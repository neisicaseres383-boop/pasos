Sube tu página HTML a GitHub 🚀

Aprende paso a paso cómo guardar tu proyecto, crear un repositorio y publicar tu página web utilizando GitHub Pages.

📖 Tutorial paso a paso

Sigue estos pasos para publicar tu proyecto.

1

👤 Crear una cuenta

Entra a GitHub y crea una cuenta. Después inicia sesión para poder crear tus repositorios.

2

📁 Crear repositorio

Pulsa en "New repository". Coloca un nombre para tu proyecto y crea el repositorio.

3

💻 Preparar HTML

Guarda tu página principal con el nombre index.html. También puedes agregar tus archivos CSS, JavaScript e imágenes.

4

⬆️ Subir archivos

Dentro del repositorio selecciona "Add file" y después "Upload files". Arrastra tus archivos y confirma los cambios.

5

🌐 Activar Pages

Ve a Settings → Pages. Selecciona la rama principal y guarda la configuración para publicar tu página.

6

🎉 Ver tu página

GitHub generará una dirección web. Ábrela en tu navegador y podrás ver tu página HTML publicada.

💻 Ejemplo de un archivo index.html 

<!DOCTYPE html>

<html>

<head>
    <title>Mi página web</title>
</head>

<body>

    <h1>¡Hola GitHub! 🚀</h1>

    <p>
        Esta es mi primera página publicada.
    </p>

</body>

</html>

💡 Consejo

Antes de subir tu proyecto revisa que el archivo principal se llame index.html y que las rutas de tus imágenes, CSS y JavaScript sean correctas. Así evitarás errores cuando publiques tu página.
